Privacy Policy

Clipper Uploader · Last updated November 3, 2026

Clipper Uploader (“the app”) is a personal tool operated by SHROOMBOI. It is used only by its owner, to upload video clips to the owner’s own YouTube channel. This policy explains what data the app touches and how it is handled.

Google user data the app accesses

When the owner signs in with Google, the app requests a single permission: https://www.googleapis.com/auth/youtube.upload. This lets the app upload videos to the owner’s YouTube channel. The app does not read the owner’s videos, subscriptions, comments, analytics, or any other account data.

How the data is used

The permission is used for one purpose: uploading clips that the app has produced to the owner’s channel, as private videos, so the owner can review them before publishing. The app does not use Google user data for advertising, profiling, or any other purpose.

What is stored, and where

  • The app keeps an OAuth refresh token, which it needs to upload on the owner’s behalf. The token is stored as an encrypted secret in the owner’s private code repository.
  • The app has no database and no website accounts. It does not collect or store personal information about any other person.
  • Videos are processed temporarily on a build server and deleted when the job ends, apart from copies the owner chooses to keep.

Sharing

The app does not sell, rent, or share Google user data with anyone. Data is not transferred to third parties, except where the law requires it.

Google API Services User Data Policy

The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The owner can revoke the app’s access at any time at myaccount.google.com/permissions, and can delete the stored token by removing the secret from the repository. Revoking access makes the stored token unusable. To ask for anything else to be deleted, write to the contact address below.

Children

The app is not directed at children and does not knowingly collect information from them.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
